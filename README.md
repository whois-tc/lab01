# Grade Classifier
This Python program asks the user for a numerical grade between 0 to 100 and returns the corresponding letter grade. 

## Requirements 

- Python 3
- No external packages required. 

## How to Run
1. Open the project in a program like VS Code 
2. Open the terminal
3. Run:

```bash 
python grade_classifier.py
```

4. Enter a number value grade from 0 to 100
